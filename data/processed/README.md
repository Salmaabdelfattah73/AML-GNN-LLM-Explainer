# Processed data

This folder holds the outputs of `preprocessing_and_feature_engineering.ipynb` and `aml_graph_construction.ipynb` (e.g. `edge_attr.npy`, `node_attr.npy`, `graph_data.pt`, scalers, encoders).

These files are not tracked in Git — they are several GB in total and can be regenerated by running the notebooks in `src/preprocessing/` and `src/graph/` in order, against the raw data in `data/raw/`.
