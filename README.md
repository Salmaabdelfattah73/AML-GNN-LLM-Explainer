# Evidence-Grounded LLM Explanations for GNN-Based Money Laundering Detection

> M.S. in Computer Science — Master Project

## 📋 Project Overview
This project builds an explainable AI system that uses
Large Language Models (LLMs) to generate human-readable
explanations for Graph Neural Network (GNN) predictions
in Anti-Money Laundering (AML) detection.

## 🚀 Getting Started

### Requirements
- Python 3.10+
- Git 2.x

### Installation
```bash
git clone https://github.com/Salmaabdelfattah73/Evidence-Grounded-LLM-Explanations-for-Graph-Neural-Network-Based-Money-Laundering-Detection.git

cd Evidence-Grounded-LLM-Explanations-for-Graph-Neural-Network-Based-Money-Laundering-Detection

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt 
```
